# Changelog
## 0.5.0 - 2026-10-12
- First Lite release, derived from Factory Core 0.5.0. Includes the sim core, two-lane belts, sources, sinks, Mk1 machines, the round-robin splitter, the fair merger, JSON/.tres data, stats, save/load (current version), the debug view and an example scene.
- Power is a stub (always full power). Tunnels, tiers, the filter splitter, bottlenecks, migrations, build mode and the demo are Pro-only.
- CC0 sprite demo scene (examples/demo.tscn, main scene) with a minimal asset subset and licence files.
- Strict headless suite: 65 checks, 13 sections.
